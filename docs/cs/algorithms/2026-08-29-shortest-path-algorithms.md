# 최단 경로 알고리즘과 성능 최적화

- **가중치 조건에 따라 알고리즘을 선택**한다: BFS, 0-1 BFS, 다익스트라, 벨만-포드, 플로이드-워셜.
- 대부분의 단일 시작점 문제에서는 **인접 리스트 + 우선순위 큐 다익스트라**가 표준이며, 시간 복잡도는 `O((V+E) log V)`이다.
- 성능의 핵심은 알고리즘뿐 아니라 **자료구조, 불필요한 완화 제거, 입력 처리, 오버플로 방지**까지 함께 최적화하는 것이다.

## 개념 설명

최단 경로 문제는 그래프에서 출발점부터 각 정점 또는 특정 목적지까지의 최소 비용을 구하는 문제다. 먼저 간선 가중치가 모두 같으면 BFS가 `O(V+E)`로 가장 빠르다. 가중치가 0 또는 1뿐이면 0-1 BFS를 사용해 `O(V+E)`에 처리할 수 있다.

음수 간선이 없다면 다익스트라를 사용한다. 우선순위 큐에서 현재 거리(`dist`)가 가장 작은 정점을 꺼내고, 인접 간선을 통해 더 짧은 경로가 발견되면 갱신한다. 이미 더 오래된 `(거리, 정점)` 상태가 큐에 남아 있을 수 있으므로 `if (d != dist[u]) continue`로 제거해야 한다. 이 조건은 중복 상태가 많은 그래프에서 성능에 큰 영향을 준다.

음수 간선이 존재하면 다익스트라는 사용할 수 없다. 이때 벨만-포드는 단일 시작점 기준 `O(VE)`이며 음수 사이클도 탐지할 수 있다. 모든 정점 쌍의 최단 경로는 플로이드-워셜의 `O(V³)`를 고려하되, 정점 수가 작을 때만 적합하다.

실전 최적화로는 간선 수가 적을 때 인접 행렬 대신 인접 리스트를 사용하고, 우선순위 큐에는 `pair<거리, 정점>`을 저장한다. 거리 타입은 큰 비용 누적을 고려해 `long long`을 사용하며, 도달 불가능한 값은 충분히 큰 `INF`로 설정한다. 특정 목적지만 필요하다면 해당 정점이 우선순위 큐에서 확정되는 순간 탐색을 종료할 수 있다. 단, 음수 가중치나 잘못된 종료 조건이 없는지 확인해야 한다.

## 코드 예시: 다익스트라

```cpp
vector<long long> dijkstra(int s, vector<vector<pair<int,int>>>& g) {
    const long long INF = 4e18;
    vector<long long> dist(g.size(), INF);
    priority_queue<pair<long long,int>,
                   vector<pair<long long,int>>,
                   greater<>> pq;
    dist[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : g[u])
            if (dist[v] > d + w)
                dist[v] = d + w, pq.push({dist[v], v});
    }
    return dist;
}
```

## 면접 질문

### 1. 다익스트라에서 음수 간선을 사용할 수 없는 이유는?

한 번 최소 거리로 확정한 정점이 이후 음수 간선을 통해 더 작아질 수 있기 때문이다. 다익스트라의 탐욕적 확정 조건이 깨진다.

### 2. BFS와 다익스트라의 성능 및 사용 조건 차이는?

BFS는 모든 간선 비용이 동일할 때 사용하며 `O(V+E)`다. 다익스트라는 음수가 아닌 서로 다른 가중치를 처리하며, 힙 기반 구현은 `O((V+E) log V)`다.

## 한 줄 정리

**최단 경로 성능 최적화는 가중치 조건에 맞는 알고리즘을 고르고, 희소 그래프·우선순위 큐·중복 상태 제거를 정확히 적용하는 데서 시작한다.**
