# 동적 계획법과 성능 최적화

## 핵심 포인트

- **중복 부분 문제**를 메모이제이션 또는 테이블로 저장해 반복 계산을 제거한다.
- 성능은 점화식보다 **상태 수, 전이 비용, 메모리 접근 패턴**에 의해 결정된다.
- 필요하지 않은 과거 상태를 버리면 공간 복잡도를 `O(N)`에서 `O(1)` 또는 `O(K)`로 줄일 수 있다.

## 개념 설명

동적 계획법(DP)은 문제를 작은 부분 문제로 나누고, 부분 문제의 결과를 재사용하는 설계 기법이다. 적용 조건은 일반적으로 **최적 부분 구조**와 **중복 부분 문제**다. 먼저 `dp[i]` 또는 `dp[i][j]`가 무엇을 의미하는지 명확히 정의하고, 초기값과 전이식을 정해야 한다.

하향식은 재귀와 메모이제이션을 사용하므로 필요한 상태만 계산할 수 있다. 그러나 재귀 호출 비용, 호출 스택 사용, 캐시 딕셔너리 오버헤드가 발생한다. 상향식은 반복문으로 테이블을 채워 호출 비용이 없고 메모리 접근이 예측 가능해 실무에서 더 빠른 경우가 많다.

시간 복잡도는 보통 `상태 개수 × 상태당 전이 수`로 계산한다. 불필요한 상태를 제거하고, 전이 과정에서 매번 최솟값을 탐색하지 않도록 누적 최솟값이나 자료구조를 활용해야 한다. 공간 최적화에서는 현재 행이 이전 행만 참조하는지 확인한 뒤 롤링 배열을 적용한다. 0/1 배낭처럼 같은 배열을 재사용할 때는 아이템을 **뒤에서 앞으로** 순회해야 한 아이템이 중복 사용되지 않는다.

성능을 더 높이려면 입력 크기에 맞춰 자료구조를 선택한다. 상태가 대부분 도달 불가능하면 희소 딕셔너리가 유리할 수 있지만, 상태가 조밀하면 연속 배열이 캐시 지역성과 인덱싱 비용 측면에서 유리하다. 큰 수의 덧셈에서는 오버플로도 확인해야 한다.

```python
def knapsack(items, capacity):
    dp = [0] * (capacity + 1)
    for weight, value in items:
        for c in range(capacity, weight - 1, -1):
            dp[c] = max(dp[c], dp[c - weight] + value)
    return dp[capacity]

print(knapsack([(2, 3), (3, 4), (4, 5)], 5))
```

## 면접 질문

### 1. 메모이제이션과 상향식 DP의 차이는 무엇인가?

메모이제이션은 필요한 상태만 재귀적으로 계산하고, 상향식은 작은 상태부터 반복문으로 계산한다. 일반적으로 상향식이 호출 및 스택 오버헤드가 적고 메모리 접근이 효율적이다.

### 2. 0/1 배낭에서 용량을 내림차순으로 순회하는 이유는 무엇인가?

현재 아이템으로 갱신된 값을 같은 순회에서 다시 사용하면 아이템이 여러 번 선택된다. 내림차순 순회는 갱신 전 상태를 참조하게 해 각 아이템을 한 번만 사용하도록 보장한다.

## 한 줄 정리

DP 최적화의 핵심은 **상태를 최소화하고, 전이를 빠르게 하며, 필요한 과거 정보만 보존하는 것**이다.
