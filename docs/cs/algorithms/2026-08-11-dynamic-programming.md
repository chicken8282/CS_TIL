# 동적 계획법(Dynamic Programming, DP)

- **핵심 조건:** 최적 부분 구조와 부분 문제 중복이 존재해야 한다.
- **설계 순서:** 상태(state) 정의 → 점화식(transition) 도출 → 초기값 설정 → 계산 순서 결정.
- **구현 방식:** 재귀 호출에 결과를 저장하는 메모이제이션과, 작은 문제부터 채우는 타뷸레이션이 있다.

## 개념 설명

동적 계획법은 큰 문제를 여러 개의 작은 부분 문제로 나누고, 각 부분 문제의 결과를 한 번만 계산해 재사용하는 알고리즘 기법이다. 단순 재귀는 같은 부분 문제를 반복 계산해 지수 시간이 될 수 있지만, DP는 결과를 저장해 시간 복잡도를 줄인다.

가장 중요한 것은 **상태 정의**다. 예를 들어 피보나치 수열에서 `dp[i]`를 “i번째 피보나치 수”라고 정의하면 `dp[i] = dp[i-1] + dp[i-2]`라는 점화식을 세울 수 있다. 이때 `dp[0]`, `dp[1]` 같은 기저 조건도 반드시 정해야 한다.

**최적 부분 구조**는 전체 문제의 최적해가 부분 문제의 최적해로 구성되는 성질이다. **부분 문제 중복**은 서로 다른 경로에서 동일한 부분 문제가 반복되는 성질이다. 두 조건이 모두 있어야 일반적으로 DP가 효과적이다.

메모이제이션은 재귀 구조가 자연스럽고 필요한 상태만 계산한다는 장점이 있지만 재귀 깊이 제한과 호출 오버헤드가 있다. 타뷸레이션은 반복문으로 구현해 안정적이고 계산 순서를 명확히 관리할 수 있다. 공간 최적화가 가능한 경우에는 이전 상태만 보관해 `O(N)` 공간을 `O(1)` 또는 `O(K)`로 줄일 수 있다.

실전에서는 “이 문제를 DP로 풀 수 있는가?”보다 “무엇을 상태로 저장할 것인가?”가 더 중요하다. 상태에 필요한 정보가 빠지면 올바른 점화식을 만들 수 없고, 불필요한 정보를 넣으면 상태 수와 메모리가 커진다.

```python
def fib(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

## 면접 질문

### 1. 동적 계획법과 분할 정복의 차이는 무엇인가?

**답변:** 둘 다 문제를 부분 문제로 나누지만, 분할 정복은 부분 문제가 대체로 독립적이다. DP는 부분 문제가 중복되므로 계산 결과를 저장해 재사용한다. 병합 정렬은 분할 정복, 피보나치와 배낭 문제는 대표적인 DP 예시다.

### 2. DP 문제의 시간 복잡도는 어떻게 계산하는가?

**답변:** 일반적으로 `상태의 개수 × 상태 하나를 계산하는 전이 비용`으로 계산한다. 예를 들어 `dp[i]`가 `N`개이고 각 상태를 `O(1)`에 계산하면 시간 복잡도는 `O(N)`이다. 2차원 배낭 문제처럼 상태가 `N × W`이면 보통 `O(NW)`이다.

## 한 줄 정리

DP는 **중복되는 부분 문제의 최적 결과를 상태로 저장하고 재사용하는 설계 기법**이다.
