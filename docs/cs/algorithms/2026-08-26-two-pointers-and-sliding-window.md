# 투 포인터와 슬라이딩 윈도우

## 핵심 요약

- **투 포인터**는 배열을 두 개의 인덱스로 가리키며 탐색 범위를 줄이는 기법이다.
- **슬라이딩 윈도우**는 연속된 구간을 창문처럼 유지하며, 한 칸씩 밀어 효율적으로 계산한다.
- 두 기법 모두 반복 탐색을 줄여 보통 **O(N²) 문제를 O(N)** 으로 개선한다.

## 개념 설명

배열을 길게 늘어선 사람들의 줄이라고 생각해 보자. 투 포인터는 두 사람이 줄의 서로 다른 위치를 가리키면서 답을 찾는 방식이다. 한 사람은 왼쪽에서 시작하고, 다른 사람은 오른쪽에서 시작할 수도 있다. 두 값의 합이 작으면 왼쪽 포인터를 오른쪽으로 옮기고, 크면 오른쪽 포인터를 왼쪽으로 옮긴다.

슬라이딩 윈도우는 손전등으로 배열의 일부만 비추는 상황과 비슷하다. 현재 비추는 구간을 윈도우라고 하며, 오른쪽 끝을 늘려 새로운 값을 포함한다. 조건을 만족하지 않으면 왼쪽 끝을 줄여 윈도우를 조절한다. 매번 구간 전체를 다시 계산하지 않고, 들어온 값과 빠진 값만 반영하는 것이 핵심이다.

예를 들어 양의 정수 배열에서 합이 `S` 이상인 가장 짧은 연속 구간을 찾을 수 있다. 오른쪽 포인터로 합을 키우고, 조건을 만족하면 왼쪽 포인터를 이동하며 가능한 짧은 구간을 확인한다. 각 포인터가 최대 한 번씩 이동하므로 시간 복잡도는 O(N)이다.

단, 일반적인 슬라이딩 윈도우는 값의 성질이 중요하다. 음수가 섞이면 왼쪽을 이동했을 때 합이 항상 감소한다고 보장할 수 없으므로, 같은 풀이를 그대로 적용할 수 없다. 문제의 배열이 정렬되어 있는지, 값이 양수인지, 구간이 연속인지 먼저 확인해야 한다.

```python
def min_len(target, nums):
    left = total = answer = 0
    for right, value in enumerate(nums):
        total += value
        while total >= target:
            length = right - left + 1
            answer = length if answer == 0 else min(answer, length)
            total -= nums[left]
            left += 1
    return answer
```

## 면접 질문

### 1. 투 포인터와 슬라이딩 윈도우의 차이는?

투 포인터는 두 인덱스로 탐색 범위를 줄이는 넓은 개념이다. 슬라이딩 윈도우는 그중에서도 **연속된 구간을 유지하며 이동**하는 방식이다.

### 2. 슬라이딩 윈도우가 O(N)인 이유는?

왼쪽과 오른쪽 포인터가 배열을 각각 최대 한 번씩 지나가기 때문이다. 겉으로 `while`문이 있어도 포인터 전체 이동 횟수는 최대 `2N`이다.

## 한 줄 정리

**두 포인터로 불필요한 재탐색을 없애고, 슬라이딩 윈도우로 연속 구간을 효율적으로 관리하자.**
